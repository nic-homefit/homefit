# Third-party sources

## Exercise metadata and animated human demonstrations

Source: [omercotkd/exercises-gifs](https://github.com/omercotkd/exercises-gifs), commit `ebf642cd90fdf73a6c73e7127e93b607b12c229e`.

The repository identifies the original dataset as [Fitness Exercises with Animations](https://www.kaggle.com/datasets/edoardoba/fitness-exercises-with-animations/data) by edoardoba and publishes its repository under the MIT License. The full supplied license is retained at `assets/exercises/LICENSE`.

The source README states: “I do not own any of the content in this repository. All rights belong to the original creators and dataset owner.” That attribution and distinction are retained here; the repository license does not purport to transfer third-party ownership.

141 source animations were selected by exercise ID, converted from GIF to H.264 MP4 with FFmpeg, and paired with WebP poster frames. The original exercise names and English instructions are retained in `exercises.js`. Chinese titles, three-step guidance and category labels were curated for this application. Each catalog entry maps to its own source animation; no external API or private credentials are used.

Demonstrations are animated anatomical human figures, not live-action trainer videos. The source GIFs sometimes illustrate the movement path using translucent intermediate poses.
