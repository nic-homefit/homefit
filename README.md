# HomeFit · Everyday Strong

保留训练、组数与重量记录、60 秒休息计时、饮食营养、训练反馈、身体测量、提醒设置及 JSON 备份恢复的静态健身网页。全新响应式界面，141 个独立动作，每个配有本地人体动画和中文步骤。

## 启动

不需要安装应用依赖、API 密钥、数据库或构建工具。使用现有 checkout；云任务已经隔离，不需要创建 Git worktree。

```sh
cd /workspace/homefit
python -m http.server 8000 --bind 0.0.0.0
```

本地验证：请求根页面，打开动作库并选择任一动作，确认动画播放。需要重新启动服务时，先确认端口上的进程属于当前任务。后台进程不会随云环境快照保留。

## 使用

- 首页选择居家 / 健身房、目标部位和 15 / 30 分钟；可从完整动作库添加、替换或移除动作。
- 动作库支持中文、英文、部位、器材搜索及分类筛选。点击卡片观看人体动画，支持暂停和 0.5× / 1× 回放。右上角「中文 / EN」即时切换界面、动作名称和步骤；语言偏好会在本机记住，切换保留尚未提交的表单及正在进行的训练。系统启用减少动态效果时默认暂停。
- 训练中记录每组重量、次数，手动启动休息计时；未完成训练可刷新后继续。完成整堂训练后写入历史。
- 旧版本的 `homefit_v2` 和 `homefit_v3_active` 储存键继续使用，保留原有数据。所有记录仍保存在当前浏览器；可在「我的数据」导出 / 导入 JSON。
- 提醒仍只保存时间和训练日；关闭网页后的推送通知需要另行接入服务。

## 验证

需要 Python Playwright 和 Chromium。云环境已提供它们；其他机器可安装 `playwright` 并执行 `playwright install chromium`，或通过 `CHROMIUM_PATH` 指定本机 Chromium。

```sh
node --check app.js
node --check exercises.js
node --check i18n.js
python -m unittest discover -s tests -v
```

15 项浏览器回归测试覆盖 141 段媒体解码、搜索筛选、暂停和慢放、减少动态效果、自定义计划持久化、训练续练与完成、计时器、营养、测量、备份恢复、旧数据兼容，以及中英文 360 / 390 / 768 / 1440 像素布局、语言持久化、英文筛选、用户输入和训练状态保留。

## 文件

- `index.html`：页面入口。
- `styles.css`：响应式深色与荧光绿主题。
- `app.js`：训练、记录、播放器和页面交互。
- `i18n.js`：中英文文案、语言偏好和切换时的状态保留。
- `exercises.js`：141 个动作的名称、器材、中文步骤、原始说明及媒体映射。
- `assets/exercises/`：141 组 WebP 缩略图和循环 MP4。视频按需加载，运行时不依赖外部素材服务。
- `THIRD_PARTY_NOTICES.md`：素材来源。

## 发布

继续使用 GitHub Pages 静态托管；将上述文件连同 `assets/` 一并发布即可，无构建步骤。修改本地 checkout 不会自动更新线上网站；将更改推送到 GitHub Pages 配置的发布分支后，由 GitHub Pages 构建并更新网站。
